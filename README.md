# echo-weather-card

Carte météo Home Assistant compacte, pensée pour les petits smart displays
(Amazon Echo Show 5 sous LineageOS/VACA + View Assist, écran 960x480).

![Aperçu de la carte à 960x480](docs/screenshot.png)

> Rendu généré via un navigateur headless en 960x480 avec des données de
> test, pas une capture sur l'Echo Show 5 lui-même — utile pour vérifier la
> mise en page en attendant une vraie capture sur l'appareil.

Statut : en développement (MVP).

Documentation complète (installation HACS, options, variables CSS, crédits)
à venir en fin de projet.
